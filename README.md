# 플립북 스튜디오

현재 프로그램 구조와 검증 범위는 [설계 문서](DESIGN.md)를 참고하세요.

Windows에서 [실행.cmd](실행.cmd)을 두 번 클릭하면 Edge 또는 Chrome의 독립 창이 열립니다. 시작 화면에 PDF 또는 EPUB을 드래그하거나 **파일 선택**을 누르세요. 파일은 이 컴퓨터의 `.data/books`에 복사되어 처리되고, 원본은 수정되지 않습니다.

**뷰어 설정**에서 상단 제목, 보조 제목, 바 색상, 투명 PNG 아이콘(2MB 이하), 본문 텍스트 선택 허용 여부를 바꿀 수 있습니다. 설정은 `.data/settings.json`에 저장됩니다. 텍스트 선택을 켠 뒤 책을 열면 하단의 **텍스트 선택** 버튼으로 지면의 글자를 드래그해 복사할 수 있습니다. 스캔 PDF처럼 실제 글자 정보가 없는 문서는 선택할 텍스트가 없습니다.

**뷰어 설정 → 재단선 기준 자동 크롭**은 기본으로 켜져 있습니다. PDF에 `TrimBox` 재단 영역이 있으면 이를 먼저 적용하고, 없으면 네 모서리의 수직·수평 재단선을 확인합니다. 새로 가져오는 파일과 ZIP 저장 결과에 적용되며, 이미 연 문서는 다시 가져와야 합니다. 감지가 불확실하면 원본 페이지를 유지합니다. 뷰어 하단 상태 메시지에 적용 여부가 표시됩니다.

문서를 연 뒤 상단 **ZIP 저장**을 누르면 먼저 Windows 저장 창에서 폴더와 파일 이름을 선택합니다. 저장 위치를 정하면 전체 페이지를 생성하며 진행 쪽수가 버튼에 표시되고, 완료되면 선택한 위치에 ZIP을 저장합니다. 저장 창에서 취소하면 ZIP 생성을 시작하지 않습니다. 이 기능은 실행.cmd로 여는 Edge/Chrome에서 지원되며, 미지원 브라우저에서는 기본 다운로드를 사용합니다. ZIP을 압축 해제하고 그 안의 `index.html`을 열면 서버 없이 열람할 수 있습니다. 페이지가 많은 책은 변환과 ZIP 생성에 시간이 걸리고 파일 크기도 커집니다.

ZIP은 웹관리자 전달용 배포 패키지입니다. `배포안내.txt`가 포함되며, 관리자는 압축을 푼 `index.html`, `css/`, `js/`, `pages/`와 라이선스 파일을 홈페이지 하위 폴더에 그대로 업로드하고 `index.html` 주소를 연결하면 됩니다. ZIP 내부의 HTML만 직접 열거나 HTML만 따로 복사하면 디자인과 지면이 나타나지 않습니다. 배포된 화면에는 파일 첨부·설정·ZIP 저장 버튼이 표시되지 않습니다.

ZIP 저장 시 지면 이미지는 글자와 도형의 픽셀을 보존하는 **무손실 WebP(.webp)**로 변환됩니다. 웹서버는 `.webp`를 `image/webp`로 제공하도록 설정해 주세요. 제작 중 사용하는 PNG 미리보기와 원본 문서는 유지됩니다. 기존 PNG 패키지는 자동으로 바뀌지 않으므로 WebP 배포본이 필요하면 다시 ZIP 저장하세요.

Python 3.11 이상, PyMuPDF, Pillow, Edge/Chrome이 필요합니다. 고정 지면 EPUB은 Node.js도 필요합니다. 최초 설치 시 `python -m pip install -r requirements.txt`를 실행하세요. 별도의 네트워크 서비스는 사용하지 않으며 서버는 `127.0.0.1`에만 연결됩니다. 실행 창을 닫으면 서버도 종료됩니다.

기존 부산대학교 80년사 v26 뷰어의 페이지 넘김, 확대, 목차, 도구 모음 디자인을 바탕으로 만들었습니다.

책 화면에서 마우스 휠을 내리면 다음 페이지, 올리면 이전 페이지로 이동합니다. 확대 상태에서는 휠이 기존처럼 지면을 이동하며, `Ctrl`+휠은 브라우저 확대·축소로 남습니다. 빠르게 연속된 휠 입력은 한 번의 페이지 넘김으로 처리합니다.

문서에 PDF 책갈피 또는 EPUB 내장 목차가 있으면 그 이동 위치를 사용합니다. 그런 정보가 없으면 앞쪽의 `목차`, `차례`, `Contents` 페이지에서 제목과 인쇄된 쪽수를 읽고 실제 본문 제목과 대조해 목차 탭을 채웁니다. 부산대학교 80년사처럼 제목 열과 쪽수 열이 분리된 고정 지면 EPUB도 처리합니다. 텍스트 정보가 없는 스캔 이미지 목차는 자동 판독하지 못하며, 위치를 확인할 수 없는 항목은 잘못된 링크를 만들지 않도록 제외합니다.
