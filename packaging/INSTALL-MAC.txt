Flipbook Studio · Mac 테스트 설치본

1. AppleSilicon은 M1/M2/M3/M4/M5 등 Apple 칩용, Intel은 Intel 칩용입니다.
   Apple 메뉴 → 이 Mac에 관하여에서 칩 또는 프로세서를 확인하세요.
2. DMG를 열고 Flipbook Studio.app을 Applications 폴더로 드래그합니다.
3. Google Chrome 또는 Microsoft Edge가 설치되어 있어야 합니다.
4. 응용 프로그램 폴더에서 Flipbook Studio를 실행합니다.
5. PDF/EPUB을 선택하고 ZIP 저장에서 위치와 이름을 지정하세요.

Python과 EPUB 처리용 Node는 앱에 포함되어 별도 설치하지 않습니다.
설정·문서 사본·로그는 ~/Library/Application Support/Flipbook Studio에 저장합니다.
앱 전용 브라우저 프로필을 사용하며 일반 브라우저 프로필은 사용하지 않습니다.
앱 창을 닫으면 로컬 제작 서버도 종료됩니다. 생성한 배포 ZIP은 별도로 유지됩니다.

이 설치본은 Apple Developer ID 서명 및 Apple 공증을 받지 않은 테스트 빌드입니다.
회사 보안 정책이나 macOS에서 실행이 차단되면 관리자에게 승인 가능 여부를 확인하세요.
정식 서명·공증 배포에는 Apple Developer 인증서와 별도 공증 절차가 필요합니다.
보안 설정을 해제하거나 터미널로 차단을 우회하지 마세요.

실행 오류 로그: ~/Library/Application Support/Flipbook Studio/application.log
